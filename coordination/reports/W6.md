## Ranking (live data, 8 gaps)
Score = support x novelty x feasibility x audience.
- support = min(1, papers/5).
- novelty = ref/(own+ref), ref = largest cell sharing this class or this mode (0.5 when there is none).
- feasibility = (solver covers class + suggested engine covers class + target region has a world) / 3.
- audience = 1.0 when the target is Norwegian AND the mode is filmable (psv, heli, ferry have an asset);
  0.6 when one holds; 0.2 when neither. Editorial weight, not evidence.

## Disagreements with the brief
- The brief says feasibility needs "data the cell needs is reachable". I took "the cell's target region", defined as Norway
  for no-norway gaps, otherwise the Norwegian region the papers name, otherwise the first foreign region, otherwise none. A
  foreign or unnamed region has no world definition, so it counts as unreachable.
- "drop no-code unless the record carries a code or data link" read literally would never emit the kind. I read it as:
  emit only when the record carries the answer (a link, or a statement of unavailability), and a link means the cell is not
  no-code. Hence the statement evidence.

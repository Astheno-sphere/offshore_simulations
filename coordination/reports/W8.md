## What an article looks like (demo, linkedin)
Hook, "What this is" (method credit + status line), "What we tested" (gates passed), "The measured answer" (+ caveat), optional figures, a method box (solver, engine, graph, commit, date, packages), assumptions (grouped by scenario section, indices stripped), sources. A sidecar `<article>.meta.json` records report path + sha256, status, figures, sources for `publish`.

## The ref-tracing rule (enforced in `build`, not only in tests)
1. Template literals and narration-rule literals may not contain a digit (lint at build).
2. Every digit run in the output (figure links and comments excluded) must be derivable from a value in `refs(report)` (`str` or fixed 0-4 decimal format). Otherwise `ArticleError: numbers ... trace to no ref`.
3. Every `{{ref:x}}` must be in front-matter `requires`; every required ref must resolve; every `{{narrate:n}}` must have rules. A narration `when` naming an unmeasured value is an error. No blank fallbacks.
4. Numbers that need conversion (hours, percent, head KPI quantiles, first paired comparison, paper-vs-ours row) are computed once in `refs()` under `derived.*`, so they are refs too.
5. Result sentences use `narrate.choose` over the refs, the same mechanism as the films: lowers / raises / inconclusive (interval includes zero) / ensemble median with deciles / single run with "no ensemble, no spread".

## Refusals
Failed gate (4_paper excepted: "did not reproduce" is a publishable finding), status `stopped at ...`, status or `reportable` saying synthetic weather / not reportable, ensemble synthetic or not ok, no `paper` block or id, no status. A report with assumptions and a template without `{{list:assumptions}}` is refused. `publish` also refuses an article whose report changed since it was built, and any file not made by `article`.

## publish
`out/<paper>/publish/`: article, `figures/` copies, `manifest.json` (sha256 of article, figures, report, optional video; sources; status word; muse result). Video is hashed, not copied. muse.ai upload only when `--muse`, a video file exists and `MUSE_AI_KEY` is set; otherwise the manifest says why it was skipped. It also writes `<paper_dir>/published.json` (`staged: true`) because that is the funnel's exit file.

## Open risks
- `published.json` is written by `publish` itself, so the human-decision stage's exit file exists as soon as the bundle is staged. It says `staged: true` and nothing is posted, but the conductor cannot tell "staged" from "approved". A real approval record belongs in `offsim decide`; left for the integrator.
- Ensemble paths were tested on a hand-built ensemble block in the `Ensemble.to_report` shape, not a real ensemble run (none is cheap offline). The headline KPI choice (`makespan_s`, variant `base`, else first) is a convention.
- Only `en` templates exist; `--lang` fails clearly for others (`<name>.<lang>.md` is the extension point).
- `thought.md` contains general method-argument prose (no numbers, no result claims). It is opinion text, not measured; review before posting.
- Status key matching is by prefix (`reproduced`, `re-run under assumptions`, `did not reproduce`, `not comparable`); a new status word falls to the default sentence quoting the status verbatim.
- ROADMAP and catalog untouched: no dependency changed (yaml already required).

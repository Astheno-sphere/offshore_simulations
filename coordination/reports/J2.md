# J2: gates that hold whatever the model decides

Branch `agent/claude/J2-hooks`. Owns: `.claude/settings.json` (new; there was none, so no existing keys to keep), `tools/hooks/gate.py`,
`tests/test_hooks_gate.py`, `docs/GUARDS.md` (6 rows under "Other rules"), `docs/HOOKS.md`, `THIRD_PARTY_NOTICES.md`, `AGENTS.md` (item 5).

## Hooks (all in `tools/hooks/gate.py`; what each blocks and how to disable: `docs/HOOKS.md`)
- H1 PreToolUse: Write/Edit/MultiEdit/NotebookEdit on `out/**/{report.json,trajectory.csv,agents.csv,run.json,state.json}`; Bash redirects, tee,
  cp/mv/rm/truncate/sed -i/dd/curl -o onto them (also inside `bash -c`, after `cd out`), python lines naming one and calling a write API.
  Pipeline recognised by command line `python -m offsim run`; a redirect from it onto a protected file is still blocked. Reads and pytest pass.
- H2 PreToolUse: writes to `offsim/cinema/rules.py`, `offsim/cinema/visual_gate.py`, `tests/golden/*`, and scenario `reported:` / tolerance lines
  only on `agent/<who>/<id>`. `git commit` touching them (M/D, not new files) needs a `why:` line (read from -m, heredoc, -F).
- H3 PreToolUse: `git add` under `out/`, `data/`, `out/reference/`; forced add of the whole tree; `git commit` with such paths in the index.
- H4 PreToolUse: UUID within 100 chars of AMPL or 40 of licence/license (dataset ids in URLs or `metadata_uuid:` excluded), BarentsWatch client
  secret. Message is only "a secret-shaped string is present".
- H5 Stop: refuses to finish while a new/modified `*storyboard*.yaml` names (`run:`) a report with a failed gate (all but `4_paper`, as story.py).
  THEIRS shows a sound pattern (G4 Stop hook with `stop_hook_active` guard), so it was built.

## Timings
Subprocess, `python3 -S`, 20 runs: Edit median 29 ms (max 36); Bash `git commit` (real `git diff` call) median 35 ms (max 39); Stop median 37 ms (max 50).
In-process decision under 1 ms for plain commands (asserted under 100 ms in a test).

## Could not enforce
- H2 "same task then claims a gate passes": a hook cannot see a claim. Only branch + `why:` enforced. Editor-message commits (no -m/-F) are not seen.
- Indirect writes: a script written then run, paths built from variables, commit messages built from variables.
- H4 checks only what is being written, not files already on disk; BarentsWatch has no fixed secret shape, so the pattern is assignment-shaped (12+ chars, letters and digits).
- Existing UUIDs beside "licence" in `catalog/tools.yaml` and `offsim/worlds/*.yaml` (Kartverket dataset ids) were false positives in a first version; fixed
  by excluding dataset ids, verified by scanning every tracked file (0 hits) and the last 300 commit messages (0 hits).
- Branch unknown (detached HEAD) is allowed (fail open). The integrator on `wip/*` branches is blocked by H2 for the files above: use an `agent/` branch or OFFSIM_HOOKS_OFF=H2.
- `python3` missing on a machine (some Windows laptops): the hook errors without blocking.

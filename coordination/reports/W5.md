## Deviations from the brief
1. `AMPL_MCP_ROOTS` uses `:` as separator, not `,`. `tools/ampl_mcp/server.py` splits roots on `os.pathsep`
   (`:` on Linux and macOS). With a comma the whole string would be one non-existent root, and every AMPL path would be refused.
2. `.mcp.json` sets `"type": "stdio"` explicitly for `ampl`.
3. No `ET-Client-Name` header in `.mcp.json`. It needs a company and application name, which would identify the user
   in a checked-in file. AGENTS.md says to set it in local Claude settings if Entur rejects calls.
4. Reports go to `coordination/reports/` (brief and coordination/README.md). SYSTEM_PLAN 3.5 and 5 say `out/agent_reports/`.
   I followed the brief. The SYSTEM_PLAN text should be updated by the integrator.
5. Model names are `haiku|sonnet|opus` as the brief asks. SYSTEM_PLAN 5 says "opus/fable" for modeller and integrator.
   I used `opus`.

# W2 conductor: report

## Files
- offsim/studio/__init__.py: funnel loader, template context, exit checks, stage derivation from artefacts.
- offsim/studio/funnel.yaml: 13 stages (feed, triage, gap*, intake, extract*, scenario, run, experiment, findings, storyboard, film, article, publish*; * = decide). Each has id, kind, command (+precheck), inputs, outputs, exit, owner skill, model tier, why. `planned: true` on findings, article, publish. `optional: true` on feed, triage, gap, experiment, findings (skipped when inputs are absent). Paths are repo-relative templates ({paper_dir}, {out}, {scenario}, ...), not relative to the paper folder.
- offsim/studio/ledger.py: load, record, block, unblock, decide, save. State file: offsim/papers/<id>/state.json. Append-only history and decisions (save() raises if earlier entries change), atomic write (tempfile + os.replace). load() derives the stage from disk when no state exists and never writes.
- offsim/studio/conductor.py: status(), next_step(id), advance(id, dry_run=True, max_steps=5), stale_branches() (git, origin/papers/* ahead of origin/main). Failed `run` -> lazy `offsim.doctor.diagnose(report_path)`; its `code` becomes the blocker, `question` the detail. Without the module: RUN-GATE-FAILED.
- offsim/__main__.py: new `status`, `next <id>`, `advance <id> [--run] [--max-steps N]`, `decide <id> <stage> --note T [--by]`; `experiment` gained `--out FILE` (run_experiment already supported out=; the funnel needs it). `doctor`, `learn`, `live` are lazy (exit 2 + message if module missing). They live in a new `LAZY` dict, not PASSTHROUGH, because tests/test_cli.py asserts the exact PASSTHROUGH set.
- tests/test_studio.py: 17 tests.

## Open risks / for the integrator
1. `learn` calls `offsim.doctor.cli.main(["learn", *args])`, `doctor` calls `main(args)`. W3 must match, or change the prefix in `LAZY` (one line).
2. state.json is not gitignored; it is written only on record/block/decide (not by status/next/dry-run). Decide whether to commit it (it is the paper-level resume) or ignore it.
3. Derived stage = stage after the furthest stage whose exit check passes. An optional stage nobody ran is still "current" in `status` (demo/helicopter show experiment-adjacent steps only through advance, which skips optional stages with missing inputs).
4. `extract` has no artefact: it is done by a recorded decision or implied by scenario.yaml existing. A hand-edited scenario.yaml therefore bypasses the extract decision.
5. `run` exit = every gate except 4_paper passes; staleness (scenario edited after the run) is only shown as a "stale artefacts" line from ledger hashes, it does not reopen the stage.
6. findings, article, publish commands are planned; advance stops there with reason `planned` (W8 owns article/publish).
7. Real PDF for intake must sit at offsim/papers/<id>/*.pdf; otherwise advance blocks with INPUT-MISSING.
8. test hygiene: ledger functions default to the real repo root; my tests always pass root=. A call without root writes into offsim/papers/ (I hit this once and removed the stray folder).

# Visual definitions (schema first, then verified rules)

Purpose: one place where the design rules for our films and graphics live, each with its source and licence, so a shot
is built from stated rules and not from taste. A rule with no verified source is marked `OURS` (derived from our own
measured references, see docs/REFERENCE_STUDY.md) or is not written. Paraphrase only; a quote stays under 15 words.
Licence rule: permissive sources may be vendored under `third_party/` with their LICENSE; a repo with no LICENSE file is
all rights reserved, so paraphrase and cite only.

Each entry: `rule | value | source (repo/path, licence) | status (verified, ours, open)`.
